# 产品一句话

QQ 里的个人 AI 管家——你说、它记、它整理、该提醒时提醒。

---

# 典型场景

## 记录

```
我：  runningman 这个综艺不错，帮我记一下
Bot： ✅ 已记到综艺清单

我：  链接是 https://xxx
Bot： ✅ 已补充链接
```

用户只管说，bot 负责判断记到哪。用户不需要知道"表"的存在。

## 查询

```
我：  我追的综艺有哪些
Bot： Running Man、极限挑战、向往的生活

我：  runningman 我看到第几季了
Bot： 你在追 Running Man，进度 S3
```

## 推荐

```
我：  好无聊
Bot： 要不看 Running Man？你追到 S3 了

我：  最近不想看 runningman
Bot： 👌 以后少推
```

bot 理解用户状态，主动建议；用户反馈影响后续推荐。

## 日程 & 提醒

```
我：  明天下午3点开会
Bot： ✅ 明天 15:00「开会」

--- 明天 14:55 ---
Bot： ⏰ 5分钟后开会
```

日程是内置的一套"提醒规则"，但底层跟"综艺清单"是同一种东西。

## 日常主动服务

```
--- 每天早上 9:00 ---
Bot： ☀️ 今天：开会 15:00、交周报

--- 任务过期时 ---
Bot： 「交周报」过了 2 天，还需要做吗？
```

---

# 能力边界

**有：**
- 自然语言记录任何事，bot 自动归类
- 按场景做推荐（无聊、不知道吃啥、想学东西…）
- 用户反馈影响推荐优先级
- 定时提醒 + 周期重复
- 每日汇总 + 过期主动询问
- 四象限（重要/紧急）排序
- 所有数据存为 markdown 文件，用户可直接打开编辑

**没有：**
- 多人协作
- Web 后台
- 数据统计
- 跟其他日历 App 同步
- 自定义提醒规则（比如"地点触发"）
