# 迭代三：通用 Agent 架构 + Web Search + 体验优化

**目标**：将"单次 AI 调用 → JSON 输出 → switch 分发"重构为通用 Agent 架构，AI 通过 Tools Call 自主决定操作，支持链式调用、Web 搜索、进度可见。

**前置条件**：迭代二完成（文件引擎 + Handler + 推荐 + 调度）

---

## 迭代三 vs 迭代二 对比

| | 迭代二 | 迭代三 |
|------|------|------|
| AI 调用 | 单次 DeepSeek → 输出 `NlParseResult` JSON | Agent Loop + Tools Call，AI 自主决定调用哪些工具 |
| 意图分发 | `switch(intent)` 硬编码 6 路分支 | `toolRegistry` 动态注册，工具自描述 |
| NL 解析 | `deepseek-parser.ts` 输出结构化 JSON | 删除，AI 直接通过 tool call 表达意图 |
| Handler | 6 个 handler 文件，每个手动解构 `NlParseResult` | 7 个 tool 文件，薄封装 file-engine |
| 搜索 | 无 | `web_search` 工具，调用 DeepSeek Anthropic 端点服务端执行 |
| 上下文 | 内存 3 条 | 两层持久化（归档 50 条 + JSONL 全量） |
| QQ 交互 | 静默等待 | 进度消息可见 + 最终回复后自动撤回 |
| 文案管理 | 散落在各文件 | 集中到 `src/messages.ts` |
| 代码量 | 约 30 个源文件 | 删除 nlp/ + handlers/ 共 10 个文件，新增 agent/ + tools/ 共 12 个文件 |

## 子任务拆分

### 任务 1：Agent 核心 — Loop + Registry + Prompt

**文件：** `src/agent/agent-loop.ts`、`src/agent/tool-registry.ts`、`src/agent/system-prompt.ts`

#### 1.1 Agent Loop 主循环

```
agentLoop(userId, text, context, hint, onProgress?)
  │
  ├── 构建 messages: [system(动态) + context(50条) + user(当前)]
  │
  ├── for 0..maxIterations(5):
  │     │
  │     ├── 调 DeepSeek chat.completions.create({ tools, tool_choice: "auto" })
  │     ├── API 失败 → 重试 1 次 → qaFallback 兜底
  │     │
  │     ├── finish_reason="stop" → 返回 content（AI 直接回复）
  │     │
  │     ├── finish_reason="tool_calls" →
  │     │     ├── onProgress 回调通知外部（发 QQ 进度消息）
  │     │     ├── 逐个执行工具 → toolRegistry.execute()
  │     │     ├── 结果截断（1500 字符）→ 注入 messages
  │     │     └── continue
  │     │
  │     └── 空回复 → 提示 AI 不要沉默 → continue
  │
  └── 达到上限 → 强制去掉 tools 再调一次 → 返回文本
```

**关键设计：**
- `MAX_ITERATIONS = 5`（可配置 `AGENT_MAX_ITERATIONS`）
- 工具结果截断 1500 字符（可配置 `AGENT_TOOL_RESULT_MAX_CHARS`）
- `onProgress` 回调：AI 调用工具时通知外部，QQ 侧发送进度消息

#### 1.2 Tool Registry — 工具注册表

```typescript
interface ToolDefinition {
  type: "function";
  function: {
    name: string;
    description: string;
    parameters: { type: "object"; properties: Record<string, unknown>; required?: string[] };
  };
}

interface ToolHandler {
  definition: ToolDefinition;
  usageGuide?: string;   // 注入 system prompt 的使用指南
  execute(args, userId): Promise<unknown>;
}

class ToolRegistry {
  register(handler): void
  getDefinitions(): ToolDefinition[]
  getUsageGuides(): string[]
  execute(name, args, userId): Promise<unknown>
}
```

**动态注册：** 每个工具文件顶层调用 `toolRegistry.register(...)`，`tools/index.ts` 通过 import 触发注册。

#### 1.3 System Prompt — 动态构建

```typescript
buildSystemPrompt(hint?) {
  // PROMPT_CORE（角色定义）
  // + 工具列表（toolRegistry.getDefinitions() 动态生成）
  // + 工具使用指南（toolRegistry.getUsageGuides() 动态收集）
  // + PROMPT_RULES（通用规则 + 回复风格）
  // + 预分类 hint（如命中）
}
```

**解耦：** 分类指南、状态推断等 domain knowledge 从 prompt 移到对应工具的 `usageGuide` 中，工具自带文档。

### 任务 2：7 个工具 — Tool Implementations

**文件：** `src/tools/create-entry.ts`、`query-entries.ts`、`update-entry.ts`、`delete-entry.ts`、`recommend-items.ts`、`folder-tree.ts`、`web-search.ts`

#### 2.1 `add_entry` — 创建条目

```
参数：title*(必填), folderPath, fileName, url, note, deadline, remindAt,
      repeatRule, interest(默认60), status, progress, importance(高/中/低)

流程：
  1. 防重复检查（findEntry）
  2. addEntry(userId, folderPath, fileName, section, input)
  3. 返回 { success, id, title, folderPath }

usageGuide: 分类指南 + 状态推断规则
```

#### 2.2 `find_entries` — 查询条目

```
参数：query, folderPath, statusFilter(待处理/进行中/已完成/搁置),
      includeDetail, limit(默认20)

流程：
  1. 有 query → findEntry 精确匹配 → searchEntries 模糊匹配
  2. 有 folderPath → getByFolder
  3. 有 statusFilter → statusChar 过滤
  4. 截断 + 序列化（includeDetail 控制字段丰富度）
```

#### 2.3 `update_entry` — 更新条目

```
参数：titleOrId*(必填), newStatus, interestDelta(-100~100),
      progress, note, importance, url

流程：
  1. findEntry / searchEntries 模糊匹配
  2. 多候选 → 返回 { ambiguous, hint } 让 AI 消歧
  3. newStatus → statusChar 映射 + customStatus
  4. updateEntry() + adjustInterest()
  5. 返回 { success, id, oldStatus, newStatus }

usageGuide: 状态转换映射 + 兴趣度调整规则
```

#### 2.4 `remove_entry` — 删除条目

```
参数：titleOrId*(必填)

流程：
  1. 模糊匹配 → 多候选消歧
  2. deleteEntry() → 从 .md + 索引移除
```

#### 2.5 `recommend_items` — 推荐

```
参数：scene*(boredom/hungry/learn), count(默认3，最大5)

流程：
  1. recommend(userId, scene, count)
  2. 场景映射：boredom→娱乐, hungry→美食, learn→学习/工作
  3. 打分 + 过滤 + 去重
  4. 返回 { items: [{id, title, interest, score}] }
```

#### 2.6 `get_folder_tree` — 目录树

```
参数：无

流程：
  1. getIndex(userId)
  2. 遍历 byFolder → 构建 { folder, files: [{name, entryCount}] }
  3. 返回 { totalEntries, folders }
```

#### 2.7 `web_search` — 网页搜索

```
参数：query*(搜索关键词)

流程：
  1. 转发到 DeepSeek Anthropic 端点
  2. 带 server tool: { type: "web_search_20250305", name: "web_search" }
  3. DeepSeek 服务端执行搜索 + 总结
  4. 从响应提取 text + web_search_tool_result.sources
  5. 返回 { result, sources }

关键：web_search 用 server tool 类型（非普通 function call），
      DeepSeek 服务端自动搜索，零外部依赖
```

### 任务 3：上下文系统 — 两层持久化

**文件：** `src/router/context-manager.ts`

```
Layer 1: data/{userId}/chat-archive.jsonl
  - 全量对话，append-only，永不删除
  - 用途：备份、调试

Layer 2: data/{userId}/context.json
  - 最近 50 条，注入 AI
  - 持久化 + 内存双存
  - 启动时从磁盘恢复
```

**API：**
```
initUserContext(userId)           // 启动时从磁盘加载
pushContext(userId, role, content) // 双写（存档 + 工作上下文 + 磁盘）
getContext(userId)                // 全量返回（格式适配 Agent Loop）
clearContext(userId)              // 清除（内存 + 磁盘）
```

### 任务 4：QQ 体验 — 进度消息 + 撤回

**文件：** `src/qq/adapter.ts`、`src/index.ts`

```
消息处理流程：
  用户消息
    → agentLoop 调工具 → onProgress 回调
      ├── adapter.sendMessage() 发进度消息 → 收集 message_id
      ├── ...
      └── AI 返回最终回复
    → adapter.recallMessage() 逐一撤回进度消息
    → 返回最终回复（保留在聊天中）
```

**QQ 界面效果：**
```
Bot: 正在搜索 深圳天气          ← 进度（几秒后消失）
Bot: 今天深圳32°C，建议带伞☂️    ← 最终回复（保留）
```

**Adapter 变更：**
- `sendMessage()` 返回值从 `void` 改为 `number | null`（message_id）
- 新增 `recallMessage(messageId)` 方法（调 `/delete_msg`）

## 数据流（以"帮我搜索 runningman 然后记下来"为例）

```
用户: "帮我搜索 runningman，然后记下来"
  │
  ▼
agentLoop(userId, text, context, hint)
  │
  ├── 第1轮: DeepSeek 判断 → 调 web_search("runningman")
  │   onProgress → QQ 发 "正在搜索 runningman" → 收集 msg_id=101
  │   web_search.execute() → Anthropic 端点 → 返回搜索结果
  │
  ├── 第2轮: DeepSeek 拿到搜索结果 + 原需求 → 调 add_entry
  │   onProgress → QQ 发 "正在记录 Running Man" → 收集 msg_id=102
  │   add_entry.execute() → fileEngine.addEntry() → 返回 { id:"a1b2", title:"Running Man" }
  │
  ├── 第3轮: DeepSeek → finish_reason="stop"
  │   返回 "已记到综艺清单，Running Man是韩国综艺..."
  │
  ▼
index.ts:
  adapter.recallMessage(101)  // 撤回 "正在搜索"
  adapter.recallMessage(102)  // 撤回 "正在记录"
  → 只有最终回复保留
```
