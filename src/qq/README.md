# qq

QQ 平台适配层。封装与 NapCat 框架的通信。

- `interface.ts` — 定义向下层传递的所有接口类型
- `adapter.ts` — QQ 适配器，基于 Express + WebSocket 接收 NapCat 事件，通过 HTTP API 发送消息。支持引用消息（reply）读取
- `connection.ts` — 连接保活：WsPing（WS 层 ping/pong）+ MsgHeartbeat（消息层心跳防空闲断连）

## QQ 适配器逻辑

适配器维护两个白名单系统：群聊白名单和用户白名单。

- 私聊消息：发送者不在用户白名单时直接拦截。
- 群聊消息：群不在群聊白名单时直接拦截。
- 群聊白名单内的普通消息：接收事件并记录日志，但目前不向下层处理。
- 群聊白名单内且 @ 自己的消息：继续检查发送者是否在用户白名单，不在则拦截。
- 通过检查的群聊 @ 消息：暂时当作用户消息交给下层，router/agent 不需要感知来源差异。

## 引用系统

核心是“用户引用新消息时，中断当前回复，让新消息进入队列处理”。它主要是交互优先级机制。

## 撤回系统

核心是“用户撤回某条消息时，停止处理、移除队列、标记撤回、清理上下文、记录撤回日志”。它是完整的生命周期处理。
